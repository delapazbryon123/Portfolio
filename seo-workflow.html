How It Works — End-to-End Flow

Stage 1: Input & Initialization

The workflow triggers via a web form. It generates a unique session ID (e.g., cc#####) that follows the data through every stage, ensuring full traceability and preventing data cross-contamination.

Stage 2: AI Business Intelligence Agent

An autonomous AI agent scrapes the target website using advanced web scraping tools. It identifies competitors, audience personas, brand personality, and unique value propositions (UVP). All data is saved as structured JSON.

Stage 3: Ranked Keyword Extraction

The system fetches up to 200 keywords the site currently ranks for. A set of logic nodes filters, de-duplicates, and sorts these by search volume, CPC, and competition levels.

Stage 4: Suggested Keywords & Intent

The engine discovers new keyword opportunities based on site content. Every keyword is run through a Search Intent API to classify it as Informational, Commercial, Transactional, or Navigational with confidence scoring.

Stage 5: Deep Keyword Expansion

This sophisticated autonomous agent executes multiple API calls to generate a massive raw list of related ideas. It then performs quality control to curate 100-150 high-value keywords, verifying the count before final insertion.
