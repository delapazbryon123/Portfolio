PR Content Generation Workflow

Multi-Modal Content Creation & Research via Telegram, enabling rapid, consistent brand communication.

Classification: Content / Telegram / AI

Product Overview

A workflow triggered via Telegram that conducts research and generates PR-ready content across multiple formats. It acts as an on-demand PR assistant.

How It Works — End-to-End Flow

Stage 1: Input via Telegram

The user sends a prompt, keyword, or breaking news link to a dedicated Telegram bot. The bot routes this directly into the n8n webhook.

Stage 2: Research & Context Gathering

An AI agent searches the web for the latest context, news, or competitor info related to the prompt to ensure the output is current and accurate.

Stage 3: Multi-Modal Content Generation

OpenAI takes the research and generates multiple pieces of content: a formal PR release, a thread for X/Twitter, a LinkedIn post, and an internal memo.

Stage 4: Delivery & Approval

The finished drafts are sent back to the user via Telegram or uploaded to a shared Google Drive/Notion workspace for final approval before publishing.
