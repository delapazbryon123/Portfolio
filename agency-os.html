What is Agency OS?

Agency OS is a full-stack SEO automation tool built to demonstrate how a modern AI agency operates. A user pastes any client website URL into the dashboard. The app securely scrapes the entire website via Firecrawl, converts it to structured Markdown, then passes it to Google Gemini 2.5 Flash acting as a senior SEO strategist — producing a fully styled, downloadable HTML report that's ready to hand directly to a client.

The entire workflow runs in under 40 seconds, replaces hours of manual research, and is deployable at zero ongoing cost using free API tiers.

How It Works — The 3-Tool Pipeline

🕸️

Step 1 — Firecrawl: Website Scraping

When the user submits a URL, the Next.js server route calls the Firecrawl API. Firecrawl crawls the entire site, strips ads and navigation noise, and returns clean Markdown — the actual content the AI needs to read intelligently.

🧠

Step 2 — Gemini 2.5 Flash: AI Strategy Engine

The clean Markdown is passed to Google Gemini with a 150-line system prompt instructing it to act as a senior SEO strategist. It generates a complete 11-section HTML report with keyword opportunity tiers, technical health scores, callout boxes, and an action plan — output directly as styled HTML.

⚡

Step 3 — Next.js + Vercel: Secure Delivery

A Next.js server API route acts as a secure middleman — API keys never touch the browser. The finished HTML report renders in a full-screen iframe with a toolbar that lets users download it with one click and print to PDF instantly.

Build Timeline

Phase 1 — Frontend Foundation

Scaffolded Next.js 16 with Tailwind CSS. Built the dark-themed dashboard UI with yellow portfolio branding, animated loading state, and full-screen iframe report viewer with toolbar.

Phase 2 — AI Engine

Built the secure Next.js server API route integrating Firecrawl for web scraping and Google Gemini for report generation. Wrote the 150-line SEO strategist prompt based on real agency report standards.

Phase 3 — Resilience & Deployment

Added a 3-tier model cascade (2.5 Flash → 2.0 Flash → flash-latest) with 503 retry logic for reliability during peak demand. Deployed to Vercel via GitHub CI/CD with zero-exposure API key handling.
