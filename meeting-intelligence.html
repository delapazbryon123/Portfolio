Meeting Intelligence

From a recording to a structured record your team can review.

The workflow

A Python worker registers a meeting, transcribes its audio when a transcript is missing, and stores segment-level analysis and meeting summaries in PostgreSQL. The pipeline runs through GitHub Actions and checks existing records to support reruns.

01 / Capture

Meeting metadata and a mono audio file enter the processing pipeline.

02 / Transcribe

Whisper generates timestamped speech segments when an existing transcript is unavailable.

03 / Analyze

Text sentiment and audio-model estimates are compared and stored for review.

04 / Summarize

Structured meeting records bring together segment counts, speaking time, and model-generated signals.

Designed for human review

Audio emotion estimates are uncertain. They do not establish what someone actually feels or intends. This portfolio describes the pipeline; it does not expose meeting recordings, participant records, or private source code.

Tools and implementation

Python · faster-whisper · emotion2vec · PostgreSQL · GitHub Actions. Processing includes checks for missing speech and existing transcripts.
